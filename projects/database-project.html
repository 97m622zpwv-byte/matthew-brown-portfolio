Relational Volunteer Database

A database project designed around volunteer records, weekly hours, and fundraising activity. The schema separates data by subject and uses primary/foreign keys to preserve relationships. Queries recombine the tables for operational reporting.

Schema

person, hours, and funds tables with primary keys, foreign keys, uniqueness, and nonnegative-value constraints.

Queries

INNER JOINs, three-table JOINs, GROUP BY, SUM, AVG, ORDER BY, and nested subqueries.

Reporting

Weekly fundraising, fundraising per hour, volunteer totals, and above-average activity.

Representative query

This query combines volunteer identity, weekly hours, and fundraising to calculate dollars raised per hour.

SELECT
    p.person_id,
    CONCAT(p.first_name, ' ', p.last_name) AS volunteer_name,
    h.week_start,
    h.hours_worked,
    f.amount_raised,
    ROUND(f.amount_raised / NULLIF(h.hours_worked, 0), 2)
        AS dollars_raised_per_hour
FROM person AS p
INNER JOIN hours AS h
    ON p.person_id = h.person_id
INNER JOIN funds AS f
    ON p.person_id = f.person_id
   AND h.week_start = f.week_start
ORDER BY h.week_start, dollars_raised_per_hour DESC;
